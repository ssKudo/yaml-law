# プロジェクトの今後のロードマップ・戦略

本リポジトリのオープンソース公開、およびその後のデスクトップアプリ展開に向けた戦略メモです。

---

## 📌 基本方針
1. **データセットの先行公開**:
   RAG開発用のクリーンな法令構造化データ（YAML/TXT/リンクグラフ）を先にオープンソース化し、開発者コミュニティからのフィードバックを得ます。ローカルLLMを用いた実験は一旦後回しとします。
2. **紹介用ランディングページ（LP）の作成**:
   「巨大で複雑なe-Govの生XML」と「構造化された本データセット」の対比や、リンクグラフの強みを視覚的に伝えるモダンなLPを作成し、GitHubリポジトリの認知度を高めます。
3. **サーバーレス自動更新システム**:
   将来的に配布するデスクトップアプリの法令データ更新は、GitHubをCDNとして活用した無料・メンテナンスフリーの差分同期システム（[配信戦略ドキュメント](file:///c:/Users/owner/git-projects/yaml-law/docs/distribution_strategy.md) 参照）で行います。
4. **ローカル環境のクリーン維持**:
   公開リポジトリの中に自分用の作業メモや実験用ファイルを置くため、`.gitignore` を利用してローカルの `private/` / `private_notes/` フォルダをGitの追跡対象外とします。
